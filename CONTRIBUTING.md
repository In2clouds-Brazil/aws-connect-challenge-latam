# Guía de contribución

¡Gracias por tu interés en contribuir a Amazon Connect Lab LATAM!

## Cómo contribuir

### Informar problemas

Si encuentras un error en la documentación, un enlace roto o una instrucción confusa:

1. Abre una **Issue** en este repositorio y describe el problema.
2. Indica el módulo y el paso donde lo encontraste.
3. Si es posible, sugiere una corrección.

No incluyas credenciales, claves ni datos personales en las evidencias.

### Sugerir mejoras

Abre una Issue de mejora (`enhancement`, si la etiqueta está disponible) y explica:

- Qué te gustaría agregar o cambiar.
- Por qué sería útil para los estudiantes.

### Enviar correcciones mediante Pull Request

1. Crea un fork de este repositorio.
2. Crea una rama: `git checkout -b fix/descripcion-de-la-correccion`.
3. Realiza los cambios necesarios.
4. Abre un Pull Request que describa claramente los cambios y su validación.

## Qué se puede mejorar

- Redacción y gramática.
- Enlaces de documentación desactualizados.
- Pasos confusos o incompletos.
- Problemas de diagnóstico no cubiertos.
- Diagramas.

## Convenciones del proyecto

- Documentación en **español latinoamericano**.
- Enlaces técnicos a la **documentación oficial de AWS**.
- Instrucciones claras y directas.
- Cada módulo debe explicar sus objetivos, requisitos y validación; conserva la secuencia progresiva del laboratorio.
- Conserva la arquitectura, los ejercicios y la duración aproximada de cuatro horas.
- Usa `es_419` para el locale de Lex V2 y `es-419` para HTML.
